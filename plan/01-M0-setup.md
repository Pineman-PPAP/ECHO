# M0: Project setup

**Goal:** `controller-free-game/echo/` exists, installs, fetches its offline assets, passes all 68 reference tests and builds. About 15 minutes.

Run every command from `controller-free-game/` unless a step says otherwise.

## Steps

### 1. Copy the reference project

```bash
mkdir -p echo
cp -r plan/reference/. echo/
```

The trailing `/.` matters: it copies dotfiles (`.gitignore`) too. Afterwards `echo/` contains `package.json`, `package-lock.json`, `tsconfig.json`, `vite.config.ts`, `.gitignore`, `scripts/`, `src/`, `tests/`. Don't change any of them in this milestone.

### 2. Create `echo/index.html` with exactly this content

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="icon" href="data:," />
    <title>ECHO</title>
    <link rel="stylesheet" href="/src/styles.css" />
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>
```

(`<link rel="icon" href="data:,">` stops the browser requesting `/favicon.ico`, which would log a 404.)

### 3. Create `echo/src/styles.css`

```css
:root {
  --bg: #000;
  --text: #cfe9ff;
  --muted: #5d7286;
  --cyan: #4fd8ff;
  --gold: #ffc94a;
  --red: #ff2a2a;
  --font: system-ui, -apple-system, 'Segoe UI', Roboto, Ubuntu, sans-serif;
  --mono: ui-monospace, 'SFMono-Regular', Menlo, Consolas, 'DejaVu Sans Mono', monospace;
}
* { box-sizing: border-box; }
html, body { margin: 0; height: 100%; background: var(--bg); color: var(--text); font-family: var(--font); overflow: hidden; }
#app { position: fixed; inset: 0; }
```

### 4. Create a placeholder `echo/src/main.ts`

```ts
import { CONFIG } from './config';

const app = document.getElementById('app')!;
app.textContent = `ECHO M0 OK. Cell size ${CONFIG.CELL_SIZE} m.`;
```

(M1 replaces this.)

### 5. Install, fetch assets, test, build

```bash
cd echo
npm install
npm run assets
npm run check
npm run build
```

Expected results:

- **`npm install`:** may print `npm warn install-scripts … esbuild`. Ignore it.
- **`npm run assets`:** prints `copied MediaPipe wasm` and then `saved model` (first run) or `model already present` (later runs). It creates `public/mediapipe/wasm/` (6 files, about 33 MB) and `public/models/face_landmarker.task` (about 3.7 MB). These are gitignored and regenerated by the same command.
- **`npm run check`:** typecheck passes and `Tests 68 passed (68)`.
- **`npm run build`:** ends with `✓ built in …`.

If `npm run assets` fails on the download (no internet), stop and tell the user. The game can't track faces without the model.

### 6. Chromium (ask the user)

You can't install system packages. Tell the user:

> Please install Chromium for the demo: `sudo pacman -S chromium`. MediaPipe's GPU face tracking is most reliable there. Firefox is only a fallback.

Continue with M1 without waiting; sim mode works in any browser.

### 7. Git (ask once)

Ask the user: *"Should I commit at the end of each milestone?"* If yes, commit only `controller-free-game/echo/` and `controller-free-game/plan/PROGRESS.md` with message `ECHO M0: project setup`. Never commit `node_modules/`, `dist/` or `public/mediapipe|models` (already in `.gitignore`). If no, don't commit at all.
