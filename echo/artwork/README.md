# Hollow artwork

Generated on 2026-10-13 with the built-in ChatGPT image generation tool, using the pose atlas as the identity reference for the catch portrait. Both PNGs retain their original alpha transparency and are saved in the project:

- `../src/assets/hollow-poses.png`: 1254 × 1254, four poses in one atlas.
- `../src/assets/hollow-catch.png`: 1254 × 1254, matching catch portrait.
- `hollow-shader-preview.jpg`: the actual game shader rendered through headless EGL/OpenGL, showing the four poses, catch portrait, and fading afterimage. This is an asset render, not a browser gameplay screenshot.
- `hollow-catch-framing.jpg`: the actual catch geometry and shader at the game's impact distance, camera FOV and landscape aspect ratio; visually checked for face placement.

These are frozen, textured planes integrated into the existing sonar snapshot presentation. They are not animated 3D models. Pose dimensions, grounded bounds, and eye positions live in `src/render/hollowArtwork.ts`; tunable height, exposure and catch framing live in `CONFIG`. The shader preserves the skin detail and real alpha, handles colour space, and keeps the existing dissolve. Textures are shared across the pool, loaded locally and bundled by Vite. The Hush and missing-file fallback retain the procedural geometry.
