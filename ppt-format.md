ps: Build a playable game or interactive experience controlled without a keyboard, mouse,
touchscreen, or conventional controller — instead through body movement, hand gestures,
voice, facial expressions, camera tracking, or sensors. The challenge isn't just swapping one
button for another input; the interaction must be technically functional, intuitive, and
meaningfully tied to gameplay (leaning to steer feels natural, waving to "press jump" is just a
disguised button). In engineering terms, you're building a pipeline: sensor/camera input →
signal processing or recognition → mapping to game actions → game logic → real-time
feedback, where low latency and reliable detection are essential.
What You Must Deliver
A working playable prototype, source code/project files, brief technical documentation covering
the input method, system architecture, and implementation, and a short demo. It doesn't need to
be a complete game, but the alternative-input system and core gameplay must work and be
demonstrable — keyboard/mouse/touchscreen/controllers may only be used for development or
debugging, never as the primary gameplay input.
Tools and Tech Stack
Build in Unity, Unreal, or Godot, using OpenCV or MediaPipe for camera-based tracking, or
custom gesture/pose models in TensorFlow, TensorFlow.js, or PyTorch. Web-based options like
JavaScript, p5.js, Phaser.js, and three.js work too, alongside voice recognition tools (Web

Speech API, Vosk, Whisper) or audio analysis for sound-based input. For hardware-driven
interaction, consider Arduino, Raspberry Pi, sensors/wearables (accelerometer, gyroscope,
EMG, heart rate), or mobile device sensors, with Python/Pygame as a quick-prototyping option.
